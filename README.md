# Snazzy Spelling

A spelling practice app for kids. Create custom word lists, then test spelling with text-to-speech audio prompts and an on-screen keyboard.

## Features

- Custom word lists with flash card review
- Spelling tests with audio playback
- Test history and per-word results
- Auto/Light/Dark theme
- PIN-protected settings for parents

## Install

Download the latest APK from [Releases](https://github.com/davenicoll/snazzy-spelling/releases).

To get automatic updates on Android, use [Obtainium](https://github.com/ImranR98/Obtainium) and add this repo as a source.
